# Language support / Dil desteği

The FAQ add-on uses XenForo's native phrase system. Import `languages/English.xml` or `languages/Turkish.xml` into the corresponding XenForo language (or a child language). The add-on follows the visitor's selected XenForo language.

FAQ questions and answers created by administrators are content, so they are not automatically machine-translated. Interface labels, buttons, settings and system messages are translated.

Yeni kullanıcıya görünen sabit metinler phrase kullanılmadan template/PHP/JS içine eklenmemelidir.
